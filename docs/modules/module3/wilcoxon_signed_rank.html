The Wilcoxon Signed-Rank Test

The Wilcoxon signed-rank test is the nonparametric alternative to the one-sample (or paired) t-test. Instead of assuming the data (or differences) are normally distributed, it only requires that the distribution be symmetric around its median. This makes it a useful option when sample sizes are small and the data look skewed, so we can’t confidently rely on the CLT.

Conditions:

  • Random sample
  • The distribution of differences is (approximately) symmetric around the median

\[H_0: \text{median} = m_0 \qquad \text{vs.} \qquad H_A: \text{median} \ne m_0 \ \ (\text{or} \ <, \ >)\]

Motivating example: Before launching the full hypertension trial, the research team ran a small pilot study with just 12 patients in the Drug A group, to get an early read on whether the drug had any effect at all. The changes in SBP (follow-up minus baseline) for these 12 patients are stored in pilot_change. With such a small sample, and visibly skewed values, we’re hesitant to assume normality—so we’ll use the Wilcoxon signed-rank test instead of a paired/one-sample t-test.

With only 11 of 12 values negative, and values ranging from -30 to +2, this small sample doesn’t look like a great candidate for assuming normality—a good case for a nonparametric test.

Ranking the Data by Hand

The signed-rank test works by: (1) taking the absolute difference from the hypothesized median (\(m_0 = 0\) here, since we’re testing whether SBP changed at all), (2) ranking those absolute differences from smallest to largest, and (3) summing the ranks of the positive differences (this sum is often called \(V\) or \(W^+\)).

Fill in the code below to calculate the absolute values of pilot_change, then rank them using rank().

# absolute values
abs_vals = abs(pilot_change)

# ranks of absolute values (smallest = rank 1)
ranks = rank(abs())

data.frame(change = pilot_change, abs_change = abs_vals, rank = ranks)
Solution 
# absolute values
abs_vals = abs(pilot_change)

# ranks of absolute values (smallest = rank 1)
ranks = rank(abs(pilot_change))

data.frame(change = pilot_change, abs_change = abs_vals, rank = ranks)

The value 2 (smallest absolute value) gets rank 1, and -30 (largest absolute value) gets rank 12. Notice only one value (2) is positive—the rest are negative.

Calculating the Test Statistic

Fill in the code below to calculate \(W^+\), the sum of the ranks corresponding to positive values of pilot_change.

# sum of ranks for positive differences
W_plus = sum(ranks[ > ])
W_plus
Solution 
# sum of ranks for positive differences
W_plus = sum(ranks[pilot_change > 0])
W_plus

[1] 1

Since only the smallest-magnitude value (rank 1) was positive, \(W^+ = 1\)—about as small as it could possibly be. This is a strong signal that the true median change is negative (i.e., SBP decreased).

If there were no real effect (median change = 0), would you expect roughly half the positive and negative values to have large ranks, or would you expect the pattern we see here (all the large ranks going to negative values)? What does our result suggest?

Using wilcox.test()

Fill in the code below to run the Wilcoxon signed-rank test on pilot_change, testing against a hypothesized median of 0.

Solution 
# Wilcoxon signed-rank test
wilcox.test(pilot_change, mu = 0)

V = 1, p-value = 0.0009766

The reported test statistic, V, matches our hand-calculated \(W^+ = 1\). The p-value (about 0.001) is well below 0.05, so we’d reject \(H_0\) and conclude the median change in SBP is significantly different from 0—consistent with what the (much larger) full trial later confirmed.

In this example, the Wilcoxon signed-rank test and a paired t-test would likely agree on the conclusion. In general, why might we prefer the Wilcoxon test over a t-test specifically for a small, skewed sample like this one?
