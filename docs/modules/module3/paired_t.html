Paired t-tests

A paired t-test is used when two measurements are taken on the same subjects (e.g., before and after treatment), rather than on two independent groups. Instead of comparing two separate samples, we compute the difference for each subject and run a one-sample t-test on those differences, testing whether the average difference is 0.

Conditions:

  • Random sample of pairs/subjects
  • Independent pairs (the differences themselves are independent across subjects)
  • \(n > 30\), or the differences follow a normal distribution in the population

\[H_0: \mu_d = 0 \qquad \text{vs.} \qquad H_A: \mu_d \ne 0 \ \ (\text{or} \ <, \ >)\]

where \(\mu_d\) is the population mean of the paired differences.

In our hypertension trial, each patient has both a baseline and a follow-up SBP measurement—the same patient, measured twice. That makes sbp_change (follow-up minus baseline) a natural candidate for a paired analysis: did SBP change significantly from baseline to follow-up, within each treatment group?

What If We Didn’t Pair?

It’s important to use a paired test when data are paired! Let’s see what happens if we (incorrectly) run an unpaired (independent samples) t-test on the same baseline and follow-up values for the Drug A group.

Fill in the code below to run the incorrect, unpaired version of the test on the Drug A group’s baseline and follow-up values (paired = F), for comparison.

# INCORRECT: unpaired test on the same (paired) data
t.test(x = data_a$, y = data_a$, paired = )
Solution 
# INCORRECT: unpaired test on the same (paired) data
t.test(x = data_a$sbp_followup, y = data_a$sbp_baseline, paired = F)

The test statistic here is smaller in magnitude than our paired version, even though we’re using the exact same data! That’s because the unpaired test ignores the fact that baseline and follow-up measurements come from the same patients, and so it fails to account for (and remove) the variability between patients—variability that the paired test cancels out by looking at within-patient differences.

Based on what you just saw, why does using the wrong (unpaired) test when data are actually paired tend to make it harder to detect a real effect, rather than easier?

Power and Sample Size for Paired t-tests

Power and sample size calculations for a paired t-test work exactly like the one-sample case, using the standard deviation of the differences.

Solution

We’d need about 156 patients to reliably detect a mean difference of 2 mmHg given this much variability in the differences.
