Two-Sample t-tests (Independent Samples)

A two-sample t-test is used to compare the means of two independent groups.

Conditions:

  • Random samples from each population
  • Independent samples (the two groups don’t contain the same subjects, and observations aren’t otherwise linked)
  • For each group: \(n > 30\), or the original variable follows a normal distribution in that population

\[H_0: \mu_1 = \mu_2 \qquad \text{vs.} \qquad H_A: \mu_1 \ne \mu_2 \ \ (\text{or} \ <, \ >)\]

By default, we’ll use the version of this test that does not assume the two groups have equal variances (sometimes called Welch’s t-test). This is the safer default, since it doesn’t require an extra assumption about equal variances—but you may see the equal-variance version used elsewhere, so we’ll cover that too.

Degrees of Freedom (Welch-Satterthwaite)

Unlike the one-sample or equal-variance tests, Welch’s t-test uses a more complicated (and typically non-whole-number) degrees of freedom:

\[df^* = \dfrac{\left(\dfrac{s_1^2}{n_1} + \dfrac{s_2^2}{n_2}\right)^2}{\dfrac{(s_1^2/n_1)^2}{n_1 - 1} + \dfrac{(s_2^2/n_2)^2}{n_2 - 1}}\]

For our example, the modified degrees of freedom are:

# pieces of the formula
A = s1^2 / n1
B = s2^2 / n2

# degrees of freedom
df_star = (A + B)^2 / (A^2 / (n1 - 1) + B^2 / (n2 - 1))
df_star

Notice this comes out close to, but not exactly, \(n_1 + n_2 - 2 = 198\) (the degrees of freedom we’d use for the equal-variance version).

Equal-Variance Version (Appendix)

You may occasionally see the equal-variance version of the two-sample t-test used instead (sometimes called the “pooled” t-test). This version assumes both groups share the same population variance, and uses a pooled variance estimate along with simpler degrees of freedom (\(n_1 + n_2 - 2\)).

Fill in the code below to run the equal-variance version of this test, using the var.equal = T argument.

Solution 
# equal-variance ("pooled") two-sample t-test
t.test(sbp_change ~ group, data = htn_trial, var.equal = T)

In our case, the two versions should give very similar results, since the two groups’ standard deviations (around 10 and 9) aren’t drastically different. The difference between the two versions tends to matter more when the groups’ variances are substantially different.
