Tests for a Single Proportion

A test for one proportion asks whether a population proportion, \(p\), differs from some hypothesized value, \(p_0\).

\[H_0: p = p_0 \qquad \text{vs.} \qquad H_A: p \ne p_0 \ \ (\text{or} \ <, \ >)\]

Conditions for the z-test: \(n p_0 \ge 5\) and \(n(1-p_0) \ge 5\). When this condition fails (usually because \(p_0\) is very small or very close to 1, or \(n\) is small), we use an exact test instead.

Motivating example: A clinic wants to check how well their flu vaccine is performing this season. Historically, around 8% of unvaccinated adults get the flu each season. Out of 150 vaccinated patients tracked this season, 9 developed the flu. Does the vaccinated group’s flu rate differ from the 8% historical (unvaccinated) benchmark?

With a p-value of about 0.37, we’d fail to reject \(H_0\)—we don’t have strong evidence that the vaccinated group’s flu rate differs from 8%. (Not every example needs to come out “significant”—this is a perfectly reasonable, informative result!)

Confidence Interval (Wald)

Fill in the code below to calculate a 95% Wald confidence interval for the true proportion.

# 95% Wald confidence interval
phat + c(-1, 1) * qnorm() * sqrt(phat * (1 - phat) / n)
Solution 
# 95% Wald confidence interval
phat + c(-1, 1) * qnorm(0.975) * sqrt(phat * (1 - phat) / n)

[1] 0.02199489 0.09800511

This interval (about 0.022 to 0.098) contains 0.08, consistent with our earlier conclusion that we don’t have strong evidence the true rate differs from 8%.
